# Jogo da Velha

Projeto de Jogo da Velha desenvolvido para uma feira escolar de profissões, com foco em demonstrar como a programação pode ser aplicada na criação de jogos simples e interativos.

## Descrição do Projeto

Este projeto implementa o jogo da velha tradicional para dois jogadores, com interface visual em grade 3x3, detecção automática de vitória/empate e opção de reinício da partida.

## Objetivo na Feira de Profissões

Apresentar, de forma prática, conceitos introdutórios de tecnologia e desenvolvimento web:

- Lógica de programação
- Interação com eventos de clique
- Manipulação de elementos da página (DOM)
- Estruturação visual com HTML e CSS

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (sem frameworks)

## Estrutura do Projeto

- index.html: estrutura do tabuleiro e da mensagem final
- style.css: estilo da interface e símbolos dos jogadores
- main.js: regras do jogo, controle de turnos e validações

## Pontos de Destaque

- Código simples e didático para apresentação escolar.
- Regras essenciais implementadas de forma clara.
- Projeto ideal para iniciar estudos em desenvolvimento web.

## Possíveis Melhorias Futuras

- Placar de partidas (X, O e empates)
- Modo jogador vs computador
- Efeitos visuais e sonoros
- Melhorias de acessibilidade
